## 🔀 Branches Overview

### `di-hilt` Branch
This branch uses **Hilt** for Dependency Injection.  
It demonstrates a clean and modular architecture following the **MVI** pattern.

### `koin` Branch
This branch uses **Koin** for Dependency Injection, along with:

- ✅ **Type-safe Navigation**
- 🎞️ **Animations using Jetpack Compose**
- 🧱 **Clean Architecture (MVI)**
- ♻️ Modular and scalable structure

Each branch showcases a different approach to Dependency Injection while maintaining consistent architecture principles.
